# 浏览器使用基础

浏览器不只是“上网软件”，也是查资料、上课、提交作业和下载文件的主要入口。先把高频操作用熟，再考虑安装插件。

## 先记住这些操作

| 操作 | Windows 快捷键 |
| --- | --- |
| 新建标签页 | `Ctrl + T` |
| 关闭当前标签页 | `Ctrl + W` |
| 重新打开刚关闭的标签页 | `Ctrl + Shift + T` |
| 打开地址栏 | `Ctrl + L` |
| 页面内查找 | `Ctrl + F` |
| 查看下载记录 | `Ctrl + J` |
| 刷新网页 | `Ctrl + R` |
| 强制刷新 | `Ctrl + F5` |

地址栏既可以输入网址，也可以直接搜索。常用网站可以加入收藏夹，但登录重要账号时要先确认地址栏域名。

## 下载和网页问题

- 下载后先知道文件保存在哪，默认通常是“下载”文件夹。
- 只有一个网站打不开时，可能是网站自身的问题；所有网站都打不开时，再检查 Wi-Fi、校园网和路由器。
- 不要在陌生网站输入密码、验证码或身份证信息。
- 遇到“电脑已中毒”“驱动过期”“立即修复”等弹窗，先关闭页面，不要按提示下载软件。

## 浏览器插件怎么管

插件可以做翻译、广告过滤、截图、密码管理和阅读增强，但它们可能读取你访问的网站内容。

安装前检查：

1. 是否来自浏览器官方扩展商店或产品官网。
2. 权限是否与用途匹配。
3. 是否真的解决了一个明确问题。

不用的插件及时禁用或删除。浏览器插件推荐集中放在[下载中心](/lab/digital-starter/docs/software-toolbox)，本篇只讲使用和判断原则。

## 网站使用习惯

- 重要网站加入收藏，不要每次从陌生搜索结果进入。
- 搜索结果中的广告不一定是官网，先核对域名。
- 论坛和搜索结果适合提供线索，涉及安全、账号、付费和系统设置时回到官方说明。

## 登录、隐私窗口和同步

- 登录浏览器账号可以同步收藏、历史记录和部分设置，但公用电脑不要开启同步。
- 无痕或隐私窗口只是不在本机保留常规历史记录，并不能让学校、公司、网站或网络服务商看不到你的访问。
- 在别人的电脑登录过邮箱、学校系统或网盘后，要退出账号，并检查是否保存了密码。
- 浏览器询问通知、摄像头、麦克风、位置或剪贴板权限时，只给当前任务确实需要的网站。

在地址栏左侧的网站信息入口中，可以查看或撤销单个网站的权限。

## 页面不正常时先做这些

1. 刷新页面，确认网址没有输错。
2. 用新标签页打开另一个网站，判断是单站故障还是网络故障。
3. 暂时关闭刚安装的插件，再重新打开页面。
4. 使用隐私窗口测试；如果能打开，问题可能来自缓存、登录状态或插件。
5. 保存报错文字和截图，再清理单个网站的数据或求助。

不要把“清空全部浏览数据”当作第一步，它可能让所有网站退出登录。也不要为了打开一个网页而关闭系统安全防护。

## 完成检查

当你能完成下面四件事，这一节就可以结束：

- 用地址栏搜索并核对一个官网域名。
- 收藏页面，再从收藏夹重新打开。
- 用 `Ctrl + J` 找到一次下载记录和本地文件。
- 查看一个网站的权限，并删除一个不再使用的插件。
