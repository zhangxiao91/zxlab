# 硬件基础与电脑设置

这份指南覆盖新电脑最常遇到的电源、接口、显示器、驱动和系统设置问题。不同品牌的按键和设置名称可能略有差异，拿不准时先查看设备说明书，不要拆机或修改陌生的 BIOS 选项。

## 先分清四种电源状态

| 操作 | 适合什么时候 | 会发生什么 |
| --- | --- | --- |
| 睡眠 | 离开几分钟到几小时 | 保留当前窗口，耗少量电，恢复最快 |
| 重启 | 软件异常、更新后或设备识别失败 | 关闭程序并重新加载系统 |
| 关机 | 长时间不用、装包携带或排查问题 | 结束本次系统运行 |
| 强制关机 | 电脑完全无响应且无法正常关闭 | 长按电源键，可能丢失未保存内容，只在最后使用 |

遇到“软件打不开、网络突然异常、外设识别失败”，优先保存文件后重启。合上笔记本通常只是睡眠，不等于关机；放进包里之前确认机器没有持续发热。

## 认识常见接口

- **USB-A**：常见长方形接口，可连接 U 盘、鼠标和键盘。
- **USB-C**：体积更小，但不同接口支持的充电、视频和传输能力可能不同，不能只看外形判断。
- **HDMI**：常用于连接显示器、电视和教室投影设备。
- **3.5 mm 音频口**：连接耳机或麦克风，部分设备使用耳麦二合一接口。
- **读卡器**：常见于相机 SD 卡或 microSD 转接卡。

接口插不进去时不要硬推，先确认方向和类型。陌生 U 盘不要直接打开其中的程序；移动硬盘正在复制文件时不要拔出。

## 安全连接外接设备

1. 保存正在编辑的文件。
2. 接入设备后等待 Windows 完成识别。
3. 在文件资源管理器或“设置 > 蓝牙和设备”中确认设备名称。
4. 复制到 U 盘或移动硬盘后，等待进度结束。
5. 对可移动存储设备执行“弹出”或“安全删除硬件”，再拔出连接线。

外接显示器没有画面时，依次检查电源、连接线、显示器输入源，再按 `Win + P` 选择复制或扩展。不要一开始就安装来源不明的“万能驱动”。

## 显示器与多屏使用

连接第二块屏幕后，打开“设置 → 系统 → 屏幕”，先点“识别”确认编号，再根据实际摆放拖动屏幕位置。常见模式：

- **仅电脑屏幕**：只用笔记本或主显示器。
- **复制**：两块屏幕显示相同内容，适合教室投影。
- **扩展**：两块屏幕组成更大的桌面，适合一边看资料、一边写作。
- **仅第二屏幕**：只用外接显示器。

文字模糊时优先使用系统标注的“推荐”分辨率，再调整缩放比例。不要为了让内容变多而把分辨率调到显示器不支持的值。投影前关闭私人通知，并确认演讲者视图不会把备注投到公共屏幕。

## 驱动和系统更新从哪里来

Windows 更新会提供大多数日常驱动。显卡、触控板、网卡或厂商功能异常时，按以下顺序处理：

1. 保存文件并重启，排除临时故障。
2. 查看 Windows 更新和“可选更新”。
3. 到电脑品牌官网按准确型号查找驱动和说明。
4. 独立显卡可再核对 NVIDIA、AMD 或 Intel 官方支持页。

不要使用无法说明来源的“驱动大师”“一键优化”或整合驱动包。更新 BIOS/UEFI 有断电或型号错误风险；只有厂商明确说明能解决当前问题时才考虑，并连接电源、核对型号和说明。

## 新电脑先检查这些设置

打开 Windows“设置”，完成一轮只读检查：

- **系统 > 显示**：缩放比例、分辨率和夜间模式是否舒服。
- **系统 > 电源和电池**：合盖、息屏和节能设置是否符合使用习惯。
- **Windows 更新**：是否有正常的系统与安全更新；更新前连接电源。
- **系统 > 存储**：系统盘剩余空间是否充足，下载目录是否堆积大文件。
- **蓝牙和设备**：移除已经不用或不认识的配对设备。
- **账户 > 登录选项**：设置可靠的 PIN，并确认恢复方式属于自己。

不要为了“优化”而批量关闭安全功能、系统服务或更新。看到不理解的选项，先搜索微软或设备厂商的正式说明。

## 电池和充电的基本习惯

- 优先使用原装或规格匹配、来源可靠的充电器和线材。
- 充电口、线材明显松动、破损或异常发热时立即停止使用。
- 不要把正在高负载运行的电脑盖在被子、枕头或衣物上。
- 电池鼓包、机身变形或出现刺激性气味时，关机断电并联系正规售后。
- 电池是消耗品，不必为了追求某个百分比频繁插拔电源。

## 15 分钟检查任务

1. 说出自己电脑上 USB、视频和音频接口的位置。
2. 检查当前显示缩放、电源模式和系统盘剩余空间。
3. 连接一个自己信任的外设，确认名称后再安全断开。
4. 记录电脑品牌、型号和 Windows 版本，求助时可以直接提供。

完成这四步后，再模拟一次“教室投影没有画面”的排查：电源、线缆、输入源、`Win + P`、系统屏幕设置。能按顺序检查并知道驱动应从哪里获取，就达到了本模块的完成标准。
