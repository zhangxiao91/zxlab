# 命令行基础

命令行是通过文字指令操作电脑的入口。它很强，也不会像图形界面那样总是提醒你。第一次练习只使用查看、切换目录和新建练习目录等低风险命令。

## 打开终端

- Windows：开始菜单搜索“终端”或“PowerShell”。
- macOS：打开“应用程序 → 实用工具 → 终端”。

提示符前面的路径通常表示当前目录。命令输入后按 Enter 执行。

## 四个核心概念

- **当前目录**：命令现在从哪里开始执行。
- **路径**：文件或目录在电脑中的地址。
- **命令**：要电脑执行的动作。
- **参数**：告诉命令具体查看或处理什么。

## 先运行只读命令

| 目的 | Windows PowerShell | macOS / Linux |
| --- | --- | --- |
| 查看当前路径 | `Get-Location` | `pwd` |
| 列出当前内容 | `Get-ChildItem` 或 `dir` | `ls` |
| 进入目录 | `Set-Location 目录名` 或 `cd 目录名` | `cd 目录名` |
| 返回上一级 | `cd ..` | `cd ..` |
| 查看文本文件 | `Get-Content README.md` | `cat README.md` |
| 清空屏幕显示 | `Clear-Host` 或 `cls` | `clear` |

路径里有空格时加引号，例如：

```powershell
cd "C:\Users\你的用户名\Documents\截图压缩练习"
```

## 完成一次路径练习

1. 打开终端，查看当前路径。
2. 进入“文档”或自己的练习目录。
3. 列出目录内容，找到 `hello.html`。
4. 返回上一级，再进入原目录。
5. 用文件资源管理器同时打开这个目录，对照图形界面和命令行显示的位置。

## 新手安全边界

- 不运行自己不理解的整段命令。
- 不把网页、聊天或 AI 给出的命令直接粘贴到管理员终端。
- 看到 `rm`、`del`、`Remove-Item`、格式化、磁盘或注册表命令时先停下。
- 命令要求管理员权限、输入密码或下载执行脚本时，先弄清原因。
- API Key、密码和验证码不要写进命令截图或发给 AI。

求助时可以提供命令、完整输出和当前路径，但先遮住用户名、令牌、内网地址和个人文件名。

## 完成标准

- 能说出当前目录是什么。
- 能列出目录、进入子目录并返回上一级。
- 能在命令行和文件资源管理器中找到同一个文件。
- 知道陌生命令不能直接复制运行。
