# 找官网、下载与安装

这项任务练习的是判断流程，不是鼓励多装软件。选择一个你确实需要、容易卸载、没有重要数据的小工具；如果系统自带功能已经够用，可以先阅读流程，再用“只找到官网、不安装”完成练习。

## 任务目标

你需要留下四项结果：

1. 软件名称和用途。
2. 经过核对的官网域名或官方应用商店页面。
3. 下载文件的名称、后缀和发布者。
4. 安装后检查结果。

不要用安全软件、驱动工具、系统清理器、破解版软件或来源不明的安装包做练习。

## 第一步：确认真的需要

先写一句话：“我需要它来做什么？”再检查 Windows 自带功能或现有软件能否完成。没有明确用途就停止，不要为了完成任务而安装。

## 第二步：找到并核对官网

1. 搜索“软件名 官网”，但不要只看搜索结果标题。
2. 核对域名、产品介绍、帮助文档、隐私政策和开发者信息。
3. 如果是开源软件，从项目官网进入官方 GitHub 仓库或发行页。
4. 记录最终域名，不点击“高速下载”“安全下载器”等第三方按钮。

拿不准时，在这里结束任务并请人复核。这也算正确判断。

## 第三步：检查安装包

下载完成后按 `Ctrl + J` 找到文件位置，记录：

```txt
软件名称：
官网域名：
安装包文件名：
文件后缀：
文件大小：
属性中显示的发布者：
```

文件名、软件名和发布者明显对不上时不要运行。Windows Security 发出警告时先停止，不要关闭 Defender。

## 第四步：安装

- 每一页都看清楚再继续，取消无关的推荐安装。
- 不懂安装路径时保留默认值。
- 出现管理员权限确认时，再次检查软件名和发布者。
- 安装界面出现无关软件、浏览器主页或搜索设置时取消。

## 第五步：检查结果

1. 从开始菜单打开软件，完成一个最小操作。
2. 检查桌面、浏览器插件和默认搜索是否出现陌生变化。
3. 在“设置 → 应用 → 已安装的应用”中找到它。
4. 在任务管理器的“启动应用”中检查它是否自动开机运行。
5. 不再需要安装包时删除安装包；软件本体要通过系统设置卸载。

## 完成标准

- 能说明为什么需要这个软件。
- 能独立回到同一个官方入口。
- 能指出安装包的真实后缀和发布者。
- 没有关闭系统安全防护，也没有安装附带软件。
- 知道以后从哪里更新和卸载。

完成后返回[电脑基础路线](/lab/digital-starter/computer)，把“软件安装与安全”标记为完成。
