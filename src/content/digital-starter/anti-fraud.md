# 反诈与账号安全基础

电脑和手机上的诈骗，通常利用的是你着急、害怕或想占便宜的几分钟。遇到下面这些情况，不要立即点击、转账或授权：

- 对方要求提供验证码、密码、身份证号、银行卡信息或屏幕共享。
- 对方自称客服、老师、学校或平台工作人员，并要求马上操作。
- 对方发送“退款”“取消会员”“账号异常”“中奖”“兼职刷单”或“高薪实习”链接。
- 网页要求下载安全控件、远程控制软件或“反诈验证工具”。
- 弹窗声称“电脑已中毒”“驱动过期”“立即修复”。
- 对方要求关闭 Defender、防火墙或 Windows 安全提示。

记住：**不急着回、不点陌生链接、不提供验证码、不向陌生账户转账、不安装对方指定的远程软件。**

## 常见场景怎么处理

| 场景 | 高风险信号 | 先做什么 |
| --- | --- | --- |
| 冒充学校、老师或辅导员 | 临时群、私聊收费、催交资料 | 通过学校官网、官方电话或已知老师再次确认 |
| 冒充平台客服退款 | 要求共享屏幕、下载会议或远程软件 | 退出通话，从 App 内客服入口重新联系 |
| 兼职刷单、垫付返利 | 先小额返利，再要求大额充值 | 立即停止，不继续垫付 |
| 游戏、演唱会、二手交易 | 脱离平台付款、发陌生二维码 | 留在正规平台完成交易 |
| 账号异常或取消会员 | 索要验证码、银行卡信息或要求转账验证 | 直接打开官方 App 检查账号，不点消息里的链接 |
| “电脑中毒”或“驱动过期” | 网页弹窗要求安装修复工具 | 关闭网页，用 Windows Security 检查 |

对方能说出你的姓名、学校、订单或部分身份证信息，也不等于对方可信。泄露的信息可能被用来增强话术。

## 远程控制是高权限操作

向日葵、UU 远程、Moonlight、会议共享屏幕等工具本身可以有正常用途，但一旦授权，对方可能看到屏幕、操作鼠标、读取文件或引导付款。

- 只允许你认识、正在协助你的人连接。
- 不向陌生客服提供设备识别码、临时密码或验证码。
- 付款、登录网银和输入密码前结束远程连接。
- 使用后关闭无人值守访问，撤销临时授权，并检查软件是否仍在后台运行。

## 账号最小保护

- 重要账号不要共用同一个密码。
- 邮箱、学校账号和支付账号使用强密码。
- 能开启两步验证就开启。
- 绑定的手机号和邮箱保持可用。
- 不把密码、验证码和身份证信息发给别人或 AI。
- 定期检查账号登录设备，移除不认识的会话。
- 密码管理器的主密码要独立、足够长，并保留可靠的恢复方式。

邮箱通常能重置其他账号，因此邮箱密码尤其不能与其他网站共用。

## 核验信息的正确入口

不要使用可疑消息里附带的电话、链接或二维码进行“核验”。自己打开官方 App、手动输入官网域名，或从银行卡、学生证、学校官网等可信来源找到联系方式。

遇到“必须立刻处理”的要求，先暂停十分钟，找一个不在当前对话里的人复核。真正的学校、银行和平台流程可以经得起独立核验。

## 如果已经点开或泄露信息

1. 停止继续操作，结束屏幕共享或远程连接，必要时断开网络。
2. 使用另一台可信设备，通过官方入口修改相关密码，优先处理邮箱、支付和学校账号。
3. 检查登录设备、转账记录、绑定手机、恢复邮箱和自动转发规则。
4. 如果泄露了支付信息或已经转账，立即联系银行和支付平台，并按所在地正式渠道报警。
5. 保留聊天记录、网址、账号、安装包、付款凭证和截图，不要为了“清理”而先删证据。

这份内容不能替代学校、银行、平台或警方的正式通知；它的作用是帮你先停一下，留出核验时间。
