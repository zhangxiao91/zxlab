# 电脑问题求助模板

遇到问题时不用先学会所有术语，只要把现场、复现步骤和安全边界说清楚，别人、搜索引擎或 AI 才能真正帮到你。

## 可以直接复制

    问题一句话概括：

    设备品牌和型号：

    操作系统及版本：

    出问题的软件、网页或设备：

    软件版本（如果能找到）：

    我原本想完成什么：

    实际发生了什么：

    完整报错文字：

    问题从什么时候开始：

    每次都会发生，还是偶尔发生：

    我做了哪些操作可以让问题再次出现：
    1.
    2.
    3.

    我已经尝试过：

    截图或录屏：

    我期望的结果：

不知道某一项就写“不清楚”，比整项删掉更有用。

## 怎么查看设备和系统

Windows 可以按 **Win + I** 打开设置，进入“系统 → 系统信息”查看设备名称、处理器、内存和 Windows 版本。也可以按 **Win + R**，输入 **winver** 查看系统版本。

软件版本通常在“设置”“帮助”或“关于”里。如果是网页问题，请写浏览器名称，例如 Edge、Chrome 或 Firefox。

## 报错不要只说“大概意思”

能复制就复制完整文字；不能复制就截图。报错里的英文、数字和文件路径经常是定位问题的关键，不要只写“它说失败了”。

截图时尽量包含：

- 报错窗口的完整标题和内容。
- 出问题的软件界面。
- 任务栏时间，方便判断发生时间。
- 如果是网页问题，保留地址栏域名，但先遮住账号和隐私参数。

## 一个填写示例

    问题一句话概括：
    下载的 zip 文件双击后提示无法打开。

    设备品牌和型号：
    联想小新 14

    操作系统及版本：
    Windows 11 24H2

    出问题的软件：
    文件资源管理器

    我原本想完成什么：
    解压老师发的课程资料。

    完整报错文字：
    Windows 无法完成提取，目标文件无法创建。

    我已经尝试过：
    重新下载一次；把文件移动到桌面；重启电脑。

    我期望的结果：
    能正常解压并打开里面的 PDF。

这种描述已经足够让别人继续排查文件是否损坏、路径是否过长、磁盘空间是否不足。

## 发出去之前先做隐私检查

遮住身份证号、手机号、学号、家庭住址、账号、二维码、密钥和私人聊天内容。截图里如果有无关窗口，也先裁掉。求助需要信息，但不需要把整台电脑的人生都直播出去。

## 发给不同对象时怎么调整

- **老师或同学**：先说明课程、作业要求和截止时间，再给出最小复现步骤。
- **软件官方支持**：补充软件版本、许可证类型、日志时间和官方工单编号，不发送密码或验证码。
- **搜索引擎**：优先搜索完整报错中的稳定关键词，删掉姓名、路径和一次性编号。
- **AI**：明确要求先诊断、不要执行修改；只提供脱敏文字和必要截图，不上传整个私人目录。

## 求助后的收尾

问题解决后记录真正原因、有效步骤和是否需要撤销临时设置。删除共享过的诊断压缩包，关闭远程控制和屏幕共享，撤销不再需要的授权。如果曾泄露密码、令牌或验证码，应立即更改或撤销，而不是只删除聊天消息。

完成标准：另一位同学只看你的描述，就能在不接触私人账号的情况下理解问题、复现条件、已尝试方法和期望结果。
